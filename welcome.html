나이스 교외체험학습 알림 · 1.9.5

신청서·보고서 처리 시점을 알려드립니다.

🧩

아이콘을 고정하세요

브라우저 오른쪽 위 확장 프로그램 → 나이스 교외체험학습 알림 → 고정. 아이콘을 눌러 설정과 최근 알림을 확인합니다.

처음 연결할 때

  1. 팝업에서 학년도·학년·반·확인 간격을 설정하고 저장합니다.
  2. 나이스에 로그인하고 신청서는 교외체험학습신청서관리, 보고서는 교외체험학습보고서관리를 엽니다. 같은 학년도·학년·반을 선택하고 접수·결재상태는 전체, 번호·성명은 빈칸으로 둡니다.
  3. 팝업의 해당 영역을 펼쳐 안내에 동의하고, 신청서는 나이스 조회 연결 시작, 보고서는 보고서 조회 연결 시작을 누릅니다. 팝업을 닫고 60초 안에 나이스의 조회를 누릅니다.
  4. 각 영역의 감시 중 상태를 확인합니다. 조회 테스트로 대상 건수를 확인할 수 있습니다.

신청서와 보고서는 각각 한 번 연결합니다. 0건이면 학습 대기 후 정상 데이터로 자동 학습합니다. 기존 사용자는 업데이트만 하면 되며 재연결·설정 저장이 필요 없습니다. 설정을 저장하면 두 연결이 초기화됩니다.

알림 조건

1차

접수대기·접수취소이면서 미상신인 신청서를 처음 발견하면 한 번 알립니다.

2차

같은 신청서가 체험 시작 5근무일 전에도 미상신이면 한 번 더 알립니다. 처음 발견한 때가 이미 5근무일 이내이면 1·2차를 합칩니다.

완결

완결 신청서(기결취소 제외)는 시작 1근무일 전부터 시작일 당일까지 처음 확인할 때 한 번 알립니다.

보고서

접수대기·미상신인 보고서를 처음 발견하면 한 번 알립니다.

기한

접수·접수대기인 완결 신청서에 대응하는 보고서가 없거나 미상신이면, 종료일을 제외한 5번째 근무일부터 신청서별 한 번 알립니다. 새 보고서 알림과 겹치면 합칩니다.

신청서 1·2차·완결 알림은 시작일 당일까지만 제공합니다. 조회 실패·불명확한 데이터는 기한 판단을 보류합니다.

근무일은 토·일요일, 공휴일, 설정한 추가 제외일을 빼고 계산합니다. 공휴일은 공개 자료를 사용하며, 자료가 없는 연도는 주말·추가 제외일만 제외합니다.

버튼 사용

조회 테스트
대상 건수만 확인하며 알림 이력은 바꾸지 않습니다.
지금 확인
즉시 조회하고 조건에 맞으면 실제 알림을 보냅니다.
화면 / Windows 알림 테스트
예시 알림을 표시·요청합니다. 실제 발송 이력은 바꾸지 않습니다.
알림 기록 초기화
최근 알림·발송 이력·미표시 기록을 지웁니다. 연결은 유지하며 대상 건은 다시 알릴 수 있습니다.
감시 중지
해당 종류의 자동 확인·재연결을 중지합니다.

매일 사용할 때

브라우저 실행과 나이스 로그인이 필요합니다. 저장한 연결은 자동으로 재개하며, 중지한 감시는 유지합니다. 팝업의 상태·마지막 조회를 확인하세요.

최근 알림은 최대 20개입니다. 페이지 알림은 나이스를 보는 동안 15초씩 표시하며 x로 닫을 수 있습니다. 미표시 알림은 탭 종료·업데이트 후에도 다음 정상 조회에서 현재 대상만 복원합니다.

나이스를 보고 있지 않으면 Windows 알림도 요청합니다. 요청 완료는 실제 배너 표시를 뜻하지 않습니다. 보이지 않으면 사용 중인 브라우저의 Windows 알림·방해 금지 설정을 확인하세요.

저장 정보와 사용 범위

설정·동의·조회 조건·알림 이력은 이 브라우저에만 저장합니다. 최근 알림에는 학생 이름·기간이 포함되며, 별도 서버로 보내지 않습니다. 보고서 본문·첨부파일은 조회하지 않습니다.

나이스·교육청의 공식 프로그램이 아닙니다. 자동 접수·상신은 하지 않으므로 최종 처리는 나이스에서 직접 확인하세요.
