처음 한 번, 이렇게 연결하세요

연결 전에 개인정보 처리 안내를 읽고 동의해 주세요. 동의 이후에는 자동 재연결이 유지됩니다.

확장 프로그램 아이콘을 눌러 학년도·학년·반과 확인 간격을 설정하고 저장합니다. 이 설정은 신청서와 보고서에 함께 적용됩니다.

팝업의 신청서와 보고서 영역은 처음에 접혀 있습니다. 제목을 누르면 각 연결 버튼과 상세 상태가 펼쳐지고, 접힌 상태에서도 연결 상태와 대상 건수를 확인할 수 있습니다. 영역을 접어도 감시는 계속됩니다.

신청서 연결

  1. 나이스에 로그인하여 교외체험학습신청서관리를 엽니다. 확장 프로그램과 같은 학년도·학년·반을 선택하고, 번호·성명은 비우고 접수·결재상태는 전체로 조회할 수 있게 설정합니다.
  2. 팝업에서 신청서 영역을 펼치고 개인정보 처리 안내에 동의합니다. 나이스 조회 연결 시작 버튼을 누르고 팝업을 닫은 뒤, 60초 안에 나이스의 조회 버튼을 누릅니다.
  3. 팝업에서 신청서 연결 상태를 확인합니다. 감시 중이면 알림 감시가 시작된 상태이며, 조회 테스트로 대상 건수를 확인할 수 있습니다.

보고서 연결

  1. 나이스의 교외체험학습보고서관리를 엽니다. 설정과 같은 학년도·학년·반을 선택하고, 접수·결재상태는 전체, 번호·성명은 빈칸으로 둡니다.
  2. 팝업에서 보고서 영역을 펼치고 보고서 정보 처리 안내에 동의합니다. 보고서 조회 연결 시작을 누르고 팝업을 닫은 뒤, 60초 안에 보고서관리의 조회 버튼을 누릅니다.
  3. 팝업에서 보고서 연결 상태를 확인합니다. 보고서 조회 테스트로 접수대기·미상신 보고서 건수를 확인할 수 있습니다.

신청서와 보고서는 각각 한 번 연결해야 합니다. 두 종류를 차례로 연결하면 함께 감시하며, 한쪽을 연결하는 동안 다른 쪽의 연결은 유지됩니다.

조회 결과가 0건이어도 검증 가능한 빈 목록이면 연결 조건을 저장하고 학습 대기 상태로 둡니다. 아직 알림 감시가 확정된 상태는 아닙니다. 첫 데이터가 들어왔을 때 서버 전체 건수와 응답 행수가 일치하면 자동 학습합니다. 전체 건수를 확인할 수 없으면 해당 목록에 데이터가 생긴 뒤 연결 시작 → 나이스 조회를 한 번 더 진행하세요. 목록이 모호하면 저장하지 않습니다.

미상신 처리 알림 + 완결 체험 시작 알림

진행상태가 접수대기 또는 접수취소이고, 결재상태가 미상신인 신청서만 대상입니다.

1차

대상 신청서를 처음 발견했을 때 한 번 알립니다.

2차

체험 시작 5근무일 전이 되었는데도 대상 상태이면 한 번 더 알립니다.

상신(진행), 회수 등 다른 결재상태는 두 알림에서 제외합니다. 처음 발견했을 때 이미 5근무일 이내라면 1·2차를 합쳐 한 번만 알립니다.
완결

진행상태가 정확히 완결인 신청서만 (기결취소 제외) 체험 시작 1근무일 전부터 시작일 당일까지 최초 확인 시 한 번 알립니다. 보라색으로 구분하며, 시작일이 지난 체험은 알리지 않습니다.

근무일은 토·일요일과 대한민국 공휴일을 제외합니다. 학교 재량휴업일은 기본적으로 포함하며, 설정의 제외일에 추가할 수 있습니다. 공휴일 데이터는 hyunbinseo/holidays-kr의 공개 자료를 참고합니다. 자료가 없는 연도는 주말과 사용자 지정 제외일만 제외하여 기한 알림을 계속 제공합니다. Chrome이 실행 중이면 하루 한 번 공개 JSON 갱신을 시도하며, 새 연도 자료가 추가되면 다음 성공 갱신 때 자동 적용합니다. 실패해도 저장 자료·내장 자료로 감시를 계속합니다. 인터넷이 되는 상태에서 Chrome을 실행하면 여러 연도 자료를 저장하여 EVPN에서도 재사용합니다. 나이스 로그인은 필요하지 않습니다. 학생 정보와 나이스 조회 조건은 공휴일 서버로 보내지 않습니다.

새 보고서 알림

주황색으로 구분합니다
접수대기이면서 미상신인 보고서를 처음 확인하면 학생 이름과 함께 한 번 알립니다. 처음 연결할 때 이미 있는 대상 보고서도 포함합니다.

버튼별 사용법

신청서와 보고서 영역을 펼치면 각각의 조회·확인·중지 버튼을 사용할 수 있습니다. ‘알림 표시 테스트’는 최근 알림 아래에, ‘알림 기록 초기화’는 동작 범위와 저장 정보 안에 있습니다.

나이스 화면 알림 오른쪽 위의 작은 원형 x 버튼을 누르면 해당 알림을 즉시 닫습니다. 버튼은 본문 첫 줄 옆에 배치되며, 긴 내용을 스크롤해도 글자와 겹치지 않고 위에 남습니다. 닫아도 최근 알림 기록과 감시는 유지됩니다.

조회 테스트
실제 나이스 조회로 대상 건수를 확인합니다. 알림 기록과 발송 이력은 바꾸지 않습니다.
지금 확인
즉시 조회하고 조건에 해당하면 실제 알림을 보냅니다.
알림 표시 테스트
최근 알림에 예시를 추가하고 연결된 나이스 페이지에 배너를 표시합니다. Windows 알림 테스트는 하지 않습니다.
알림 기록 초기화
최근 알림과 모든 종류의 발송 이력을 지웁니다. 연결은 유지되며, 다음 확인에서 기존 신청서도 다시 알릴 수 있습니다.
중지
신청서 자동 확인과 자동 재연결을 중지합니다. 보고서는 ‘보고서 감시 중지’로 따로 중지합니다.

매일 사용할 때

한 번 연결하면 다음에 나이스에 접속했을 때에도 자동으로 연결을 시도합니다. 나이스 로그인 상태가 아닌 경우, 데이터 조회가 불가능해 알림이 뜨지 않습니다.

업데이트할 때마다 다시 연결할 필요는 없습니다. 같은 확장 프로그램의 업데이트는 설정·동의·신청서와 보고서의 조회 조건·알림 이력을 유지합니다. 이미 열려 있는 나이스 탭에서도 최신 코드를 준비해 자동으로 감시를 재개하며, 화면을 강제로 새로고침하지 않습니다. 업데이트 후 별도로 설정 저장이나 연결 시작을 누르지 않아도 됩니다.

나이스 탭이 없거나 로그인 전이면 기다렸다가 다시 시도합니다. 사용자가 중지한 감시는 그대로 유지합니다. 학년도·학년·반 설정을 바꾸거나 나이스 조회 구조가 달라진 경우에는 새 연결이 필요할 수 있습니다. 확장을 제거 후 재설치하거나 다른 확장 프로그램으로 설치한 경우에는 기존 연결 정보가 이어지지 않습니다.

한쪽 조회가 실패해도 다른 쪽의 감시는 계속됩니다. 설정을 저장하면 두 연결을 다시 진행해야 합니다. 최근 알림은 신청서와 보고서를 합해 최대 20개를 저장합니다.

아이콘의 ! 표시나 팝업의 상태 안내를 확인하세요. 다시 로그인한 후에도 연결되지 않으면 나이스 탭을 새로고침하거나 연결 절차를 다시 진행하세요. 연결 중단 안내는 Windows 알림으로 보내지 않습니다.

실제 알림은 나이스 페이지 배너와 확장 프로그램의 최근 알림으로 확인합니다. 연결된 나이스 탭을 보고 있지 않을 때에만 Windows 알림도 표시합니다.

교육청별 *.neis.go.kr 주소를 지원합니다. 교육청이나 나이스 업데이트에 따른 화면·응답 차이는 추가 확인이 필요할 수 있습니다.

개인정보와 사용 범위

보고서 연결 조건과 중복 알림 방지 기록은 신청서와 별도로 저장하며 보고서 알림에도 학생 이름이 포함됩니다. 보고서 본문이나 첨부파일을 열거나 다운로드하지 않습니다.

조회는 사용 중인 나이스 로그인과 권한으로 이루어집니다. 설정, 자동 연결용 조회 조건, 알림 이력 등 모든 데이터는 이 브라우저에 저장합니다. 이 확장프로그램은 별도의 서버를 사용하지 않습니다. 자동 연결용 조건에는 학교·사용자 식별값이 포함될 수 있습니다.

나이스 또는 교육청의 공식 프로그램이 아닌 독립 확장 프로그램입니다. 신청서를 자동 접수·상신하지 않으며, 최종 처리는 나이스에서 직접 확인해 주세요.
