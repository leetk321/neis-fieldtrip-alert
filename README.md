# 나이스 교외체험학습 알림

담임교사가 지정한 학년·반의 교외체험학습 신청서와 보고서를 확인하는 Chrome 확장 프로그램입니다. 현재 버전은 **1.9.5**, 최소 Chrome 버전은 **120**입니다. 교육청·나이스의 공식 프로그램이 아닙니다.

[Chrome 웹 스토어에서 설치](https://chromewebstore.google.com/detail/lenkoapndfkiklobnggppllbabjdafpk)

## 알림 조건

| 알림 | 대상 | 시점 |
| --- | --- | --- |
| 신청서 1차 | 접수대기·접수취소이면서 미상신 | 처음 발견했을 때 한 번 |
| 신청서 2차 | 같은 신청서가 계속 미상신 | 시작 5근무일 전부터 시작일 당일까지 한 번 |
| 완결 체험 시작 | 정확히 완결인 신청서, 기결취소 제외 | 시작 1근무일 전부터 시작일 당일까지 한 번 |
| 새 보고서 | 접수대기이면서 미상신인 보고서 | 처음 발견했을 때 한 번 |
| 보고서 기한 | 완결 신청서에 대응하는 보고서가 없거나 미상신 | 종료일을 제외한 5번째 근무일부터 신청서별 한 번 |

근무일은 주말·공휴일·설정한 추가 제외일을 빼고 계산합니다. 신청서 1·2차·완결 알림은 시작일 당일까지만 제공합니다. 처음 발견했을 때 이미 5근무일 이내인 신청서는 1·2차를 합칩니다.

**보고서 기한 알림**은 접수·접수대기이며 결재상태가 정확히 완결인 신청서에 적용합니다. 보고서의 접수상태와 관계없이 미제출·결재상태 미상신을 확인합니다. 두 목록을 새로 조회해 같은 학교·계정·학년도·학년·반의 학생 번호와 체험기간으로 비교하며, 조회 실패·중복·불명확한 상태는 판단을 보류합니다. 늦게 연결해도 현재 조건에 해당하면 알립니다. 새 보고서와 기한 알림이 동시에 발생하면 기한 알림 하나로 합칩니다.

## 처음 사용하기

1. 웹 스토어에서 설치합니다. 소스로 설치하려면 `chrome://extensions`에서 개발자 모드를 켜고 `manifest.json`이 있는 폴더를 ‘압축해제된 확장 프로그램을 로드합니다’로 선택합니다.
2. 팝업에서 학년도·학년·반·확인 간격을 설정하고 저장합니다.
3. 나이스의 **교외체험학습신청서관리 / 교외체험학습보고서관리**에서 같은 학년도·학년·반을 선택합니다. **접수·결재상태는 전체, 번호·성명은 빈칸**으로 둡니다.
4. 팝업의 각 영역을 펼쳐 안내에 동의하고 **나이스 조회 연결 시작 / 보고서 조회 연결 시작 → 팝업 닫기 → 60초 안에 해당 나이스 화면의 조회**를 진행합니다.
5. 신청서·보고서의 **감시 중** 상태를 확인합니다. 0건이면 **학습 대기**로 연결 조건을 보관하고, 정상 데이터가 생겼을 때 자동 학습합니다.

신청서와 보고서는 각각 한 번 연결합니다. 기한 알림에는 두 연결이 모두 필요합니다.

**이미 연결한 1.9.3·1.9.4 사용자는 업데이트만 하면 됩니다. 재연결·설정 저장이 필요 없습니다.** 보고서를 연결한 적이 없다면 최초 보고서 연결만 진행하세요. 설정 저장은 두 연결을 초기화하므로 설정을 변경할 때만 사용하세요.

## 매일 사용하기

브라우저를 실행하고 나이스에 로그인하면 감시를 자동 재개합니다. 사용자가 중지한 감시는 유지하며, 나이스 화면을 강제로 새로고침하지 않습니다. 팝업의 접힌 제목 줄에서 연결 상태와 대상 건수를 확인할 수 있습니다.

페이지 알림은 나이스를 보는 동안 15초씩 표시하며 **x**로 닫습니다. 미표시 알림은 탭 종료·브라우저 재시작·업데이트 후에도 다음 정상 조회에서 현재 대상만 복원합니다. 최근 알림은 최대 20개입니다.

나이스를 보고 있지 않으면 Windows 알림도 요청합니다. 실제 배너 표시는 브라우저·운영체제 설정에 따라 달라집니다. 보이지 않으면 팝업의 **화면 알림 테스트 / Windows 알림 테스트**로 확인하세요. 요청 완료는 실제 배너 표시를 뜻하지 않습니다.

## 저장 정보와 사용 범위

설정·동의·조회 조건·알림 이력은 이 브라우저에 저장합니다. 최근 알림에는 학생 이름·체험기간이 포함되며 별도 서버로 보내지 않습니다. 보고서 본문·첨부파일은 조회하지 않습니다. **알림 기록 초기화**는 최근 알림·발송 이력·미표시 기록을 지우고 연결은 유지합니다.

브라우저 종료·절전·로그아웃 중에는 조회하지 않습니다. 교육청별 도메인을 지원하지만 모든 교육청의 화면·응답 구조를 실환경 검증한 것은 아닙니다. 자동 접수·상신 기능은 없으며 최종 처리는 나이스에서 직접 확인하세요.
