나이스 교외체험학습 알림 · 1.5.3

신청서 확인, 조금 더 편하게.

우리 반의 처리할 신청서를 확인하고, 체험 시작 전 한 번 더 알려드립니다.

🧩

크롬 오른쪽 위에 고정해 두세요

퍼즐 모양 → 나이스 교외체험학습 알림 → 고정 핀
고정한 아이콘을 누르면 설정, 조회 상태, 최근 알림을 볼 수 있습니다.

처음 한 번, 이렇게 연결하세요

  1. 확장 프로그램 아이콘을 눌러 학년도·학년·반과 확인 주기를 설정하고 저장합니다. 학년도는 3월부터 다음 해 2월까지이며 1~2월에는 전년도 학년도를 사용합니다.
  2. 나이스에 로그인하여 교외체험학습신청서관리를 엽니다. 확장 프로그램과 같은 학년도·학년·반을 선택하고, 번호·성명은 비우고 접수·결재상태는 전체로 조회할 수 있게 설정합니다.
  3. 확장 프로그램의 나이스 조회 연결 시작 버튼을 누르고 팝업을 닫은 뒤, 60초 안에 나이스의 조회 버튼을 누릅니다.
  4. 확장 프로그램에서 감시 중 또는 신청서 학습 대기를 확인합니다. 학습 대기는 아직 알림 감시가 확정되지 않은 상태입니다. 조회 테스트로 현재 대상 건수를 확인할 수 있습니다.

조회 결과가 0건이어도 검증 가능한 빈 목록이면 연결 조건을 저장하고 첫 신청서 학습을 기다립니다. 서버 전체 건수와 응답 행수가 일치하면 자동 학습합니다. 전체 건수를 확인할 수 없으면 신청서가 생긴 뒤 연결 시작 → 나이스 조회를 한 번 더 진행하세요. 목록이 모호하면 저장하지 않습니다.

미상신 처리 알림 + 완결 체험 시작 알림

진행상태가 접수대기 또는 접수취소이고, 결재상태가 미상신인 신청서만 대상입니다.

1차

대상 신청서를 처음 발견했을 때 한 번 알립니다.

2차

체험 시작 5근무일 전이 되었는데도 대상 상태이면 한 번 더 알립니다.

상신(진행), 회수 등 다른 결재상태는 두 알림에서 제외합니다. 처음 연결했을 때 이미 5근무일 이내라면 두 알림이 함께 발생할 수 있습니다.
완결

진행상태가 정확히 완결인 신청서만 (완결(기결취소) 제외) 체험 시작 1근무일 전부터 시작일 당일까지 최초 확인 시 한 번 알립니다. 그보다 일찍 조회한 기록은 발송 여부에 영향을 주지 않습니다. 보라색으로 구분하며, 시작일이 지난 체험은 알리지 않습니다.

근무일은 토·일요일과 대한민국 공휴일을 제외합니다. 학교 재량휴업일은 기본적으로 포함하며, 설정의 제외일에 추가할 수 있습니다. 공휴일 데이터는 hyunbinseo/holidays-kr의 공개 자료를 참고합니다. 자료가 없는 연도는 주말과 사용자 지정 제외일만 제외하여 기한 알림을 계속 제공합니다. Chrome이 실행 중이면 하루 한 번 공개 JSON 갱신을 시도하며, 새 연도 자료가 추가되면 다음 성공 갱신 때 자동 적용합니다. 실패해도 저장 자료·내장 자료로 감시를 계속합니다. 인터넷이 되는 상태에서 Chrome을 실행하면 여러 연도 자료를 저장하여 EVPN에서도 재사용합니다. 나이스 로그인은 필요하지 않습니다. 학생 정보와 나이스 조회 조건은 공휴일 서버로 보내지 않습니다.

버튼별 사용법

조회 테스트
실제 나이스 조회로 대상 건수를 확인합니다. 알림 기록과 발송 이력은 바꾸지 않습니다.
지금 확인
즉시 조회하고 조건에 해당하면 실제 알림을 보냅니다.
알림 표시 테스트
최근 알림에 예시를 추가하고 연결된 나이스 페이지에 배너를 표시합니다. Windows 알림 테스트는 하지 않습니다.
알림 기록 초기화
최근 알림과 모든 종류의 발송 이력을 지웁니다. 연결은 유지되며, 다음 확인에서 기존 신청서도 다시 알릴 수 있습니다.
중지
자동 확인과 자동 재연결을 중지합니다. 다시 사용하려면 연결하세요.

매일 사용할 때

한 번 연결하면 다음에 나이스에 접속했을 때에도 자동으로 연결을 시도합니다. 나이스 로그인 상태가 아닌 경우, 데이터 조회가 불가능해 알림이 뜨지 않습니다.

아이콘의 ! 표시나 팝업의 상태 안내를 확인하세요. 다시 로그인한 후에도 연결되지 않으면 나이스 탭을 새로고침하거나 연결 절차를 다시 진행하세요. 연결 중단 안내는 Windows 알림으로 보내지 않습니다.

실제 알림은 나이스 페이지 배너와 확장 프로그램의 최근 알림으로 확인합니다. 연결된 나이스 탭을 보고 있지 않을 때에만 Windows 알림도 표시합니다.

교육청별 *.neis.go.kr 주소를 지원합니다. 교육청이나 나이스 업데이트에 따른 화면·응답 차이는 추가 확인이 필요할 수 있습니다.

개인정보와 사용 범위

조회는 사용 중인 나이스 로그인과 권한으로 이루어집니다. 설정, 자동 연결용 조회 조건, 알림 이력 등 모든 데이터는 이 브라우저에 저장합니다. 이 확장프로그램은 별도의 서버를 사용하지 않습니다. 자동 연결용 조건에는 학교·사용자 식별값이 포함될 수 있습니다.

나이스 또는 교육청의 공식 프로그램이 아닌 독립 확장 프로그램입니다. 신청서를 자동 접수·상신하지 않으며, 최종 처리는 나이스에서 직접 확인해 주세요.
