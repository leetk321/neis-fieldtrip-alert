# 사용 안내

## 설정과 최초 연결

학년도는 3월부터 다음 해 2월까지입니다. 2026학년도는 2027년 2월까지 사용하며, 2027년 3월에는 설정 후 다시 연결합니다. 학년·반은 처음에 비어 있습니다. 확인 간격은 3·5·10·15분 중 선택합니다.

팝업의 신청서·보고서 영역은 기본으로 접혀 있으며, 제목 줄에 연결 상태와 대상 건수를 표시합니다. 제목을 누르면 상세 상태와 연결·조회·중지 버튼을 볼 수 있습니다. 영역을 접어도 감시는 계속됩니다.

나이스 교외체험학습신청서관리에서 같은 학년도·학년·반을 선택하고, 접수·결재상태 전체 및 번호·성명 빈칸으로 조회합니다. 팝업의 ‘신청서’ 영역을 펼치고 개인정보 처리 안내에 동의한 뒤 연결 시작을 누릅니다. 팝업을 닫고 60초 안에 나이스 조회를 눌러 실제 요청을 연결합니다.

보고서는 별도로 ‘교외체험학습보고서관리’에서 같은 학년도·학년·반, 접수·결재상태 전체, 번호·성명 빈칸을 선택합니다. 팝업의 ‘보고서’ 영역을 펼치고 보고서 정보 처리에 동의합니다. ‘보고서 조회 연결 시작’을 누른 뒤 팝업을 닫고 60초 안에 나이스 조회를 누릅니다. 두 종류를 차례로 연결하면 병행 감시하며, 연결을 새로 시작한 종류만 갱신합니다.

## 0건 연결

화면 총건수가 0이고 응답에서 하나의 빈 목록을 식별하면 요청 조건을 저장하여 ‘신청서 학습 대기’ 상태로 둡니다. 서버 전체 건수와 응답 행수를 검증할 수 있으면 첫 정상 데이터에서 자동 학습합니다. 전체 건수를 확인할 수 없으면 첫 데이터 발견 후 연결 시작 → 나이스 조회로 재확인합니다. 여러 빈 배열이나 부분 응답은 추측해서 연결하지 않습니다.

## 매일 사용

같은 확장 프로그램의 업데이트는 기존 신청서·보고서 연결, 동의와 알림 이력을 유지합니다. 업데이트 전에 열어 둔 나이스 탭에도 최신 코드를 준비하고 자동 연결하므로 연결을 다시 학습시키거나 화면을 강제로 새로고침할 필요가 없습니다. 탭이 로딩 중이거나 로그인 전인 경우에는 기다렸다가 자동으로 다시 시도합니다. 복구 대기 중에는 1분 간격의 예약 작업도 사용하며, 실제 실행 시점은 Chrome 상태에 따라 달라질 수 있습니다. 감시를 중지한 종류는 자동으로 켜지 않습니다.

업데이트 후 설정 저장을 다시 누를 필요는 없습니다. 설정 저장은 조회 조건을 변경하는 기능으로 두 연결을 초기화합니다. 새 학년도·학년·반으로 변경하거나 나이스 응답 구조가 달라진 경우에는 다시 연결해야 할 수 있습니다. 확장 제거 후 재설치하거나 다른 확장 ID로 설치하면 저장 정보가 이어지지 않습니다.

동일 교육청·학교·계정의 로그인된 나이스 탭이 있으면 재연결을 시도합니다. 통신 오류나 화면 변경으로 감시가 중단될 수 있습니다. 마지막 성공 조회와 상태를 확인하고, 필요하면 재로그인·새로고침·재연결하세요. 신청서 데이터 오류와 공휴일 다운로드 실패는 다릅니다. 공휴일 실패만으로 신청서 감시를 중단하지 않습니다.

## 버튼

| 버튼 | 동작 |
| --- | --- |
| 조회 테스트 | 실제 응답을 확인하며 발송 이력·최근 알림은 변경하지 않음 |
| 지금 확인 | 즉시 정상 감시를 실행하여 필요하면 알림 발송 |
| 알림 표시 테스트 | 예시 최근 알림·페이지 배너 표시, 실제 신청서 이력과 Windows 알림은 변경하지 않음 |
| 알림 기록 초기화 | 최근 알림과 모든 단계의 발송 이력 삭제, 연결 유지 |
| 감시 중지 | 자동 확인·자동 재개 중지, 저장 정보 유지 |
| 설정 저장 | 기존 연결 조건 삭제, 다시 연결 필요 |

초기화 후 아직 알림 기간에 있는 신청서는 다시 알릴 수 있습니다. 이미 시작일이 지난 신청서는 초기화해도 알리지 않습니다. 같은 신청서의 날짜가 바뀌어도 이미 보낸 단계는 반복하지 않습니다. 처음 발견한 미상신 신청이 이미 5근무일 이내라면 1·2차를 합쳐 한 번만 알립니다. 이때 두 단계 모두 완료로 기록해 다음 조회에서도 반복하지 않습니다. 더 일찍 1차를 받은 신청서는 기준일에 2차 알림을 보냅니다.

최근 알림은 최대 20개입니다. 페이지 배너는 순서대로 15초씩 표시합니다. Windows 알림의 표시 범위는 운영체제 설정에 영향을 받습니다. 아이콘 건수는 미상신 건수이며, 시작일이 지난 미상신도 건수에는 남을 수 있습니다.

## 보고서 알림

‘접수대기’이면서 ‘미상신’인 보고서를 처음 발견하면 주황색으로 한 번 알립니다. 보고서는 체험 종료 후에도 제출되므로 날짜 제한 없이 확인합니다. 접수취소·접수·상신(진행)·회수·완결 등 다른 상태는 무시합니다. 처음 연결할 때 이미 있는 대상 보고서도 알림 대상입니다.

‘보고서 조회 테스트’는 알림 이력을 바꾸지 않습니다. ‘보고서 지금 확인’은 실제 알림을 처리합니다. ‘보고서 감시 중지’는 보고서만 중지하고 기존 ‘감시 중지’는 신청서만 중지합니다. ‘알림 기록 초기화’는 모든 신청서·보고서 이력을 지우되 두 연결을 유지합니다. 설정을 저장하면 두 연결을 다시 진행해야 합니다. 보고서 건수는 팝업의 보고서 영역에서 확인합니다.
