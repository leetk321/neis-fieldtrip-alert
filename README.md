# 🔔 나이스 교외체험학습 알림

나이스의 **교외체험학습신청서관리**에서 지정한 학년·반의 신청서를 주기적으로 확인하고, **미상신 신청의 처리 시기**와 **완결된 체험학습의 시작**을 알려주는 교사용 Chrome 확장 프로그램입니다.

## 주요 기능

### 신청서 상태에 따른 알림

| 구분 | 알림 대상 | 알림 시점 |
|---|---|---|
| 1차 알림 | 접수대기·접수취소 상태이면서 미상신인 신청서 | 처음 발견했을 때 1회 |
| 2차 알림 | 접수대기·접수취소 상태이면서 미상신인 신청서 | 체험 시작 5근무일 전부터 시작일 당일까지 최초 확인 시 1회 |
| 완결 알림 | 진행상태가 정확히 `완결`인 신청서 | 체험 시작 1근무일 전부터 시작일 당일까지 최초 확인 시 1회 |

- 모든 알림은 **체험 시작일 당일까지만** 제공합니다.
- `상신(진행)`, `회수` 등은 미상신 알림 대상에서 제외합니다.
- `완결(기결취소)`는 완결 알림 대상에서 제외합니다.
- 완결 신청서를 미리 확인했더라도, 알림 대상 기간에 들어오면 별도로 알려줍니다.
- 처음 연결할 때 이미 존재하는 신청서도 알림 대상에 포함됩니다. 이때 조건에 따라 1차·2차 알림이 함께 발생할 수 있습니다.

### 학생 이름과 체험기간 표시

- 모든 신청서 알림에 **대상 학생 이름**을 표시합니다.
- 완결 알림에는 **학생별 체험기간**을 함께 표시합니다.
- 완결 알림은 미상신 알림과 다른 색상으로 구분합니다.
- 최근 알림은 최대 **20개**까지 보관합니다.
- 나이스 화면 안에 알림을 표시하며, 연결된 나이스 탭을 보고 있지 않을 때는 Windows 알림도 요청합니다.

### 자동 연결

한 번 연결하면 다음에 나이스에 접속했을 때에도 자동으로 연결을 시도합니다.

- 저장된 교육청·학교·계정 정보를 확인해 연결을 재개합니다.
- 확인 간격은 **3분·5분·10분·15분** 중 선택할 수 있습니다.
- 학년도는 **해당 연도 3월부터 다음 해 2월까지**로 계산합니다.

### 근무일 계산과 공휴일 저장

토·일요일, 대한민국 공휴일, 사용자가 지정한 추가 제외일을 제외해 근무일을 계산합니다.

공휴일 데이터는 [hyunbinseo/holidays-kr](https://github.com/hyunbinseo/holidays-kr)의 공개 자료를 참고합니다.

- Chrome 실행 중 하루 한 번 갱신을 시도합니다.
- 다운로드한 자료는 브라우저에 저장해 EVPN 등 인터넷 연결이 제한된 환경에서도 사용합니다.
- 다운로드에 실패하면 저장 자료 또는 내장 자료를 사용합니다.
- 자료가 없는 연도는 **주말과 추가 제외일만 제외**하여 계속 동작합니다.
- 학교 재량휴업일 등은 필요에 따라 추가 제외일로 설정할 수 있습니다.

## 사용 방법

1. Chrome 우측 상단의 **퍼즐 모양 아이콘**을 누르고 확장 프로그램을 고정합니다.
2. 확장 프로그램에서 **학년도·학년·반·확인 간격**을 설정하고 저장합니다.
3. 나이스의 **교외체험학습신청서관리** 화면을 엽니다.
4. 확장 프로그램과 같은 학년도·학년·반을 선택합니다.
   - 접수·결재상태: **전체**
   - 번호·성명: **빈칸**
5. 확장 프로그램의 **나이스 조회 연결 시작**을 누릅니다.
6. 팝업을 닫고 **60초 안에 나이스의 조회 버튼**을 누릅니다.
7. 확장 프로그램에서 연결 상태를 확인합니다.

최초 조회 결과가 0건이면 신청서 학습 대기 상태로 연결 정보를 저장할 수 있습니다. 이후 정상 신청서 응답을 확인해 학습하며, 전체 건수 확인이 필요한 경우에는 화면 안내에 따라 다시 연결해야 합니다.

## 확인·테스트 기능

| 기능 | 설명 |
|---|---|
| 조회 테스트 | 실제 조회가 가능한지 확인합니다. 알림 이력은 변경하지 않습니다. |
| 지금 확인 | 즉시 조회하고, 조건에 맞는 신청서 알림을 처리합니다. |
| 알림 표시 테스트 | 예시 알림으로 표시 상태를 확인합니다. |
| 알림 기록 초기화 | 연결을 유지한 채 알림 기록을 초기화합니다. 다음 조회에서 같은 신청서 알림이 다시 발생할 수 있습니다. |
| 감시 중지 | 주기적인 신청서 조회와 자동 재개를 중지합니다. |

## 동작 조건

- **Chrome 120 이상**이 필요합니다.
- 로그인된 나이스 탭과 해당 신청서를 조회할 권한이 필요합니다.
- 브라우저 종료, PC 절전, 나이스 로그아웃 또는 나이스 탭이 없는 동안에는 신청서를 확인할 수 없습니다.
- 알림은 실시간 서버 푸시가 아닌 **주기적인 조회 결과**를 기준으로 발생합니다.
- Windows 알림 표시는 브라우저 및 운영체제의 알림 설정에 따라 달라집니다.
- 교육청별 `*.neis.go.kr` 주소를 대상으로 동작하지만, 모든 교육청 환경에서 실제 동작을 검증한 것은 아닙니다.
- 나이스 화면·응답 구조 또는 학교·계정이 변경되면 다시 연결해야 할 수 있습니다.

## 개인정보와 저장 정보

설정, 자동 연결용 조회 조건, 알림 이력 등 모든 데이터는 **이 브라우저에 저장**합니다. 알림 이력에는 학생 이름과 체험기간이 포함될 수 있습니다.

이 확장 프로그램은 별도의 서버를 사용하지 않습니다. 공휴일 자료 갱신을 위해 GitHub에 접속하지만, 학생 정보나 나이스 조회 조건을 전송하지 않습니다.

자세한 내용은 [개인정보 안내](docs/PRIVACY.md)를 참고하세요.

## 사용 범위

사용자에게 조회 권한이 있는 신청서를 확인하고 알림을 제공하는 보조 도구입니다. 신청서를 접수하거나 상신·승인하는 기능은 제공하지 않습니다.

교육부·교육청 또는 나이스에서 제공하는 공식 제품이 아닙니다.
