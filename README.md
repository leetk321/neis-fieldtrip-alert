# 나이스 교외체험학습 알림

담임교사가 지정한 학년·반의 교외체험학습 신청서와 보고서를 확인하는 Chrome 확장 프로그램입니다. 현재 버전은 **1.8.1**, 최소 Chrome 버전은 **120**입니다. 교육청·나이스의 공식 프로그램이 아닙니다.

## 알림

| 종류 | 대상 | 시점 |
| --- | --- | --- |
| 1차 | 미상신 접수대기·접수취소 | 처음 발견했을 때 한 번 |
| 2차 | 미상신 접수대기·접수취소 | 시작 5근무일 전부터 시작일 당일까지 한 번 |
| 완결 | 정확히 완결인 신청서, 완결(기결취소) 제외 | 시작 1근무일 전부터 시작일 당일까지 한 번 |
| 새 보고서 | 접수대기이면서 미상신인 보고서 | 처음 발견했을 때 한 번 · 주황색 |

처음 발견했을 때 이미 5근무일 이내인 미상신 신청서는 1·2차를 합쳐 한 번만 알립니다. 더 일찍 1차를 받은 신청서는 기준일에 2차 알림을 보냅니다.

시작일 다음 날부터 모든 신청서 알림을 제외합니다. 보고서는 체험 후 제출되므로 이 날짜 제한을 적용하지 않습니다. 모든 알림에 학생 이름을 표시하며 완결 알림에는 체험기간도 표시합니다. 이름 필드가 모호하면 ‘이름 확인 필요’를 표시합니다. 일찍 조회한 기록은 완결 알림을 소진하지 않습니다. 보고서의 접수취소·상신(진행)·회수·완결 등 다른 상태는 알림 대상에서 제외합니다.

나이스 페이지 배너와 최근 알림을 제공하며, 연결된 나이스 탭이 활성·포커스 상태가 아닐 때 Windows 알림도 표시합니다. 공휴일은 공개 자료를 갱신해 사용하고, 통신 실패에도 저장 자료·내장 자료·주말 기준으로 계산을 계속합니다.

## 시작하기

1. 소스를 내려받아 보관합니다.
2. `chrome://extensions`에서 개발자 모드를 켜고 ‘압축해제된 확장 프로그램을 로드합니다’를 선택합니다.
3. `manifest.json`이 있는 폴더를 선택하고 확장을 고정합니다.
4. 학년도·학년·반을 저장한 뒤 나이스 신청서관리의 조회 조건을 동일하게 설정합니다.
5. 접수·결재상태는 전체, 번호·성명은 빈칸으로 설정합니다.
6. 팝업의 **신청서** 영역을 펼치고 개인정보 처리 안내에 동의합니다. ‘나이스 조회 연결 시작’을 누르고 팝업을 닫은 뒤 60초 안에 나이스 ‘조회’를 누릅니다.
7. 보고서 알림도 받으려면 **교외체험학습보고서관리**를 열고 같은 조건을 선택합니다. 팝업의 **보고서** 영역을 펼쳐 보고서 정보 처리 안내에 동의한 뒤 **보고서 조회 연결 시작 → 팝업 닫기 → 60초 안에 나이스 조회**를 진행합니다.

신청서·보고서 영역은 팝업을 열 때 기본으로 접혀 있습니다. 접힌 제목 줄에서 각 연결 상태와 대상 건수를 확인하고, 제목을 누르면 연결·조회·중지 버튼과 상세 안내를 볼 수 있습니다. 영역을 접어도 감시는 계속됩니다.

신청서와 보고서는 각각 한 번 연결하면 함께 자동 감시합니다. 최초 연결 당시 이미 존재하는 접수대기·미상신 보고서도 알립니다. 각 감시는 따로 중지할 수 있고 한쪽 조회 오류가 다른 쪽을 중단하지 않습니다. 학년·반 등 설정을 저장하면 두 조회 모두 다시 연결해야 합니다. 알림 기록 초기화는 두 종류의 이력을 함께 지우며 연결은 유지합니다.

같은 확장 프로그램을 업데이트할 때는 신청서·보고서를 다시 연결할 필요가 없습니다. 1.8.0부터 설정·동의·조회 조건·알림 이력을 유지하고, 이미 열려 있는 나이스 탭에서도 최신 코드를 준비해 감시를 자동 재개합니다. 이를 위해 scripting 권한을 사용하며 나이스 화면을 강제로 새로고침하지 않습니다. 탭이 닫혀 있거나 로그인 전이라면 준비될 때까지 기다립니다. 사용자가 중지한 감시는 자동으로 켜지 않습니다.

나이스 화면 알림 오른쪽 위의 **닫기 ×**로 해당 알림을 바로 닫을 수 있습니다. 긴 알림을 스크롤해도 닫기 버튼은 위에 남으며, 최근 알림 기록과 감시는 유지됩니다. 알림 표시는 입력 중인 화면의 포커스를 가져오지 않습니다.

## 제한

로그인된 나이스 탭이 필요합니다. 브라우저 종료·절전·로그아웃 중에는 조회하지 않습니다. 교육청별 도메인을 지원하지만 모든 교육청의 화면·응답 구조를 실환경 검증한 것은 아닙니다. 0건 조회는 검증 가능한 빈 목록일 때 조건을 저장하며, 서버 전체 건수가 없으면 첫 데이터 발견 후 화면 재확인이 필요합니다.

자동 접수·상신 기능은 없습니다. 최종 처리는 나이스에서 확인하세요.
