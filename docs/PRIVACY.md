# 개인정보와 외부 통신

프로그램의 공개용 상세 안내는 [privacy.html](../privacy.html)입니다. 스토어 제출 시 해당 파일을 공개 웹 주소에 게시해야 하며 GitHub 소스에 파일을 올리는 것만으로 웹 페이지가 호스팅되지는 않습니다.

## 브라우저 저장

학년도·학년·반, 확인 주기, 제외일, 학교·계정과 연결된 조회 템플릿, 신청서 식별값의 해시와 단계별 발송 이력, 학생 이름·완결 체험기간을 포함한 최근 알림 최대 20개, 공휴일 캐시·갱신 정보를 저장합니다. 조회 템플릿 본문에는 학교·사용자 식별값이 원문으로 포함될 수 있습니다. 응답 전체는 저장하지 않습니다.

storage.local은 TRUSTED_CONTEXTS로 제한하며 콘텐츠 스크립트는 직접 접근하지 않습니다. 이 설정은 암호화가 아니며 PC 사용자로부터 저장 데이터를 보호하지 않습니다. 로그인 비밀번호를 입력받지 않고 Cookie·Authorization 요청 헤더를 저장하지 않습니다.

## 통신

- 연결한 동일 출처의 나이스: 기존 로그인 세션으로 목록 재조회
- GitHub Raw: 고정된 공개 공휴일 JSON 다운로드. 학생·학교·계정·조회 조건은 요청에 포함하지 않으며 쿠키·리퍼러를 제외

개발자 서버·광고·분석 서비스는 없습니다. GitHub는 IP 주소 등 통상적인 접속 정보를 수신할 수 있습니다. 알림에는 학생 이름이 있으므로 화면 공유 및 OS 알림 표시를 고려하세요.

## 삭제

알림 기록 초기화는 최근 알림과 단계별 발송 이력을 지웁니다. 설정 저장은 이전 연결 조건을 지웁니다. 중지는 자동 감시만 멈춥니다. 확장 제거 시 해당 확장 저장 정보가 삭제됩니다. 공휴일 캐시는 학생 데이터와 별개입니다.

## 1.6.0 보고서 알림

보고서는 별도 동의 후 조회를 연결합니다. 보고서의 학생 이름·번호, 학년·반, 식별값, 진행상태 등 목록 응답을 메모리에서 처리하고 보고서 본문·첨부파일은 조회하지 않습니다. 보고서 연결 조건, 식별값 해시와 발송 이력, 보고서 정보 처리 동의 버전·시각을 이 브라우저에 저장합니다. 최근 알림에는 보고서 학생 이름도 포함되며 신청서와 합해 최대 20개입니다. 보고서 조회 조건도 학교·사용자 식별값을 포함할 수 있으며 별도 서버로 전송하지 않습니다. 알림 기록 초기화는 두 종류의 이력을 지우고, 설정 저장은 두 연결 조건을 지웁니다. 중지 버튼은 종류별로 작동합니다.

## 1.5.4 동의 및 요청 처리

최초 연결 전 개인정보 처리 내용을 안내하고 동의 버전·시각을 저장합니다. 이전 버전 사용자는 다시 동의하고 연결해야 합니다. 동의 전에는 자동 학교·계정 확인이나 신청서 조회를 시작하지 않습니다. 연결 준비와 실제 조회 클릭 직후 필요한 요청만 추적하며 허용 목록의 일반 헤더만 임시 처리합니다. 인증 헤더를 따로 보관하지 않습니다.

데이터는 신청서 알림과 자동 연결에만 사용하며 Chrome 웹 스토어 사용자 데이터 정책의 제한적 사용 요건을 준수합니다. 저장소 접근 제한은 암호화가 아니며, 기존 평문 로컬 저장 구조는 유지됩니다.
