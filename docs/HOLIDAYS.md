# 공휴일 데이터

## 출처와 갱신

[hyunbinseo/holidays-kr](https://github.com/hyunbinseo/holidays-kr)의 `public/basic.json`을 사용합니다. 연도별 날짜와 공휴일 명칭 배열을 담은 자료이며 MIT 라이선스입니다. 확장은 고정된 GitHub Raw 주소에서 JSON만 받고 원격 코드를 실행하지 않습니다.

설치·업데이트·Chrome 시작 시 자료를 확인하고, Chrome이 실행 중이면 시간별 예약 작업으로 갱신 시점을 확인합니다. 정상 다운로드 후에는 24시간 동안 다시 요청하지 않고, 실패 후에는 최소 한 시간 간격으로 재시도합니다. 나이스 로그인이나 감시 설정은 필요하지 않습니다. 브라우저 종료 중에는 갱신하지 않습니다. 새 연도가 저장소에 추가되면 다음 성공 갱신부터 계산에 반영됩니다.

연도·실제 날짜·명칭 배열·자료 크기·연도별 기본 날짜와 개수를 검증합니다. 성공한 연도는 교체하여 원본의 수정·삭제를 반영하고, 원본에 없는 연도는 이전 자료를 보존합니다. 형식 검증은 공휴일의 법적 정확성을 보증하지 않습니다.

## 실패 시 동작

1. 마지막으로 검증·저장한 해당 연도 자료
2. 해당 연도의 내장 자료 (2025~2027)
3. 자료가 없으면 토·일요일과 사용자 지정 제외일

다운로드·파싱 실패는 신청서 감시를 중단하지 않습니다. 팝업 ‘근무일 계산’에서 최근 갱신 시각과 실패 여부를 확인할 수 있습니다. 학교 재량휴업일과 추가 임시공휴일은 제외일에 직접 입력할 수 있습니다.

## 내장 자료

`calendar.js`의 기존 자료를 오프라인 예비 자료로 유지합니다. 한국천문연구원·우주항공청 월력요항과 정부 공고를 참고하여 작성한 날짜 목록입니다. 원격 자료가 없는 상태의 새로운 연도는 공휴일을 추측하지 않습니다.

공휴일 자료를 받는 요청에는 학생 정보, 학교·계정, 나이스 요청 본문을 넣지 않습니다. 쿠키·리퍼러를 제외하지만 통상적인 접속 정보는 GitHub에 전달될 수 있습니다.


## EVPN 사용

인터넷에 연결된 상태에서 Chrome을 실행하면 공개 자료를 받아 로컬에 보관합니다. 학년도가 두 해에 걸치므로 한 연도만 잘라 저장하지 않고 공개 자료의 여러 연도를 함께 저장합니다. 예를 들어 2026학년도 계산에는 2026년과 2027년 날짜가 사용될 수 있습니다.

EVPN에서는 저장 자료로 계산합니다. 신청서 조회 시 공휴일 네트워크 요청을 기다리지 않습니다. 변경된 공휴일은 다음 인터넷 연결 상태에서 성공한 정기 갱신에 반영되며, 인터넷에 연결되지 않은 동안 새 공고를 알 수는 없습니다. 내장 자료에도 없는 연도는 주말·추가 제외일로 계산합니다.
