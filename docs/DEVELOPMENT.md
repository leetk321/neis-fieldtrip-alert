# 개발과 검증

## 구조

| 파일 | 역할 |
| --- | --- |
| manifest.json | 버전·권한·진입점 |
| hook.js | 연결 시간 내 실제 조회 요청 캡처 |
| content.js | 화면·계정 확인, 응답 정규화, 배너 |
| core.js | 학년도·스키마 학습·신청서 필터·알림 계획 |
| report-core.js | 보고서 스키마 학습·접수대기/미상신 필터, 날짜 제한 없음 |
| report-watcher.js | 독립 보고서 연결·동의·주기 조회·중복 이력 |
| calendar.js | 근무일·내장 및 다운로드 날짜 계산 |
| holiday-sync.js | 공개 JSON 검증·캐시·갱신 |
| background.js | 저장소 제한·주기 조회·발송 이력·알림 |
| popup.* / welcome.* / privacy.html | 사용자 화면 |

## 테스트

Node.js 20 이상에서 저장소 루트 기준으로 실행합니다.

```sh
node --test tests/*.cjs
```

Chrome API는 모형으로, 공휴일 HTTP는 모의 응답으로 검증합니다. 보고서와 신청서의 독립 연결·다른 진행상태 무시·중복 방지·0건 학습·조회 테스트·자동 재개도 검증합니다. 보고서 화면의 조회 조건과 표 필드는 경기도 나이스에서 확인했습니다. 모든 교육청의 실제 응답·설치 상태·EVPN 환경은 별도 검증 대상입니다.

## 패키징

Python 3에서 실행합니다. 실행 파일만 포함한 스토어 ZIP을 dist에 생성하며 manifest.json은 최상위에 둡니다. 외부 라이선스 고지도 포함합니다.

```sh
python scripts/package.py
```

## 배포 확인

버전은 manifest.json이 기준입니다. UI 버전과 CHANGELOG도 함께 갱신하세요. 새 접근 권한이 있으면 Chrome의 안내를 확인합니다. 소스 ZIP은 개발용이며 스토어에는 실행 파일 ZIP을 업로드합니다. 게시자 연락처·공개 개인정보처리방침·스크린샷·심사 절차 설명이 별도로 필요합니다. 게시 작업은 패키징에 포함되지 않습니다.

실제 학생 데이터·로그인 정보·조회 응답·PC 로컬 저장소를 저장소나 이슈에 올리지 마세요. 코드 전체의 배포 라이선스는 제작자가 결정해야 하며 외부 공휴일 자료의 MIT 고지만으로 자동 결정되지 않습니다.
