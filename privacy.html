나이스 교외체험학습 알림 · 1.8.1

개인정보 처리 안내

시행일: 2026년 9월 11일 · 버전 1.8.1

목적과 접근 정보

사용자가 지정한 학년·반의 미상신 접수대기·접수취소 신청을 확인하고 최초 발견 및 미상신 처리 기한 알림을 제공합니다. 완결된 신청서에는 체험 시작 1근무일 전 알림을 제공합니다. 사용자가 연결한 나이스 조회 응답에는 학생 이름·번호, 신청서 식별값, 체험 날짜 등 개인정보가 포함될 수 있으며, 해당 응답은 대상 판단을 위해 메모리에서 처리합니다.

별도로 연결한 교외체험학습보고서관리의 접수대기·미상신 보고서를 확인해 최초 발견 시 한 번 알립니다. 보고서 응답의 학생 이름·번호, 학년·반, 보고서 식별값과 진행상태 등을 대상 판단을 위해 메모리에서 처리합니다. 보고서 내용이나 첨부파일을 열거나 다운로드하지 않습니다.

브라우저에 저장하는 정보

로컬 저장소 접근은 확장 내부의 신뢰된 컨텍스트로 제한합니다. 나이스에 삽입된 콘텐츠 스크립트는 로컬 저장소를 직접 읽을 수 없습니다. 이 접근 제한은 저장 정보를 암호화하거나 PC 사용자로부터 보호하는 기능은 아닙니다.

학년도·학년·반, 확인 주기, 제외일, 확인 시각과 건수, 최근 알림 최대 20개, 해시 처리한 계정·학교·신청서 식별값과 알림 단계 이력을 로컬에 저장합니다. 해시값은 익명정보임을 보장하지 않습니다.

자동 재연결을 위해 교육청 주소, 조회 요청 본문과 응답 구조 정보를 저장합니다. 조회 요청 본문에는 학교·사용자 식별값이 원문으로 포함될 수 있습니다. 학생 목록 응답 전체는 저장하지 않습니다. 대상 학생 이름과 완결 신청서의 체험기간은 알림 문구에 포함하여 최근 알림 최대 20개에 저장합니다. 로그인 비밀번호와 Cookie·Authorization 헤더를 수집·저장하지 않습니다.

보고서 연결 조건, 보고서 식별값 해시와 발송 이력은 신청서와 구분하여 저장합니다. 보고서 알림에도 학생 이름이 포함되며, 신청서와 보고서를 합해 최근 알림 최대 20개를 보관합니다. 공휴일 자료와 갱신 정보도 이 브라우저에 저장합니다.

전송 및 제3자 제공

조회 요청은 기존 브라우저 로그인 세션을 이용하여 연결한 동일 출처의 나이스로만 전송합니다. 개발자 서버로 데이터를 보내지 않으며 광고, 분석 도구, 개인정보 판매를 사용하지 않습니다. 공휴일 갱신 시 GitHub의 raw.githubusercontent.com에서 공개 JSON을 다운로드합니다. 학생 정보·학교·계정·조회 조건을 전송하지 않고 쿠키와 리퍼러도 제외합니다. 다만 GitHub에는 IP 주소 등 통상적인 접속 정보가 전달될 수 있습니다. 원격 실행 코드를 내려받지 않습니다.

조회 연결과 동의

같은 확장 프로그램의 업데이트에서는 기존 설정·동의·연결 조건·알림 이력을 유지합니다. scripting 권한으로 저장된 동의와 교육청 주소에 해당하는 나이스 탭에 패키지 내부 코드를 준비하여 자동 연결을 복구합니다. 학교·계정이 저장값과 일치한 뒤 조회하며, 사용자가 중지한 감시는 다시 켜지 않습니다. 새 연결은 사용자가 동의하고 연결 시작을 누른 탭에서 준비합니다. 나이스 화면을 강제로 새로고침하거나 원격 실행 코드를 내려받지 않습니다.

최초 연결 전에 팝업에서 개인정보 처리 내용을 안내하고 동의를 받습니다. 1.5.3 이하 버전에서 처음 업데이트하는 사용자는 한 번 동의하고 다시 연결해야 합니다. 동의 전에는 자동 학교·계정 확인과 신청서 조회를 시작하지 않습니다. 동의 버전과 시각을 브라우저에 저장합니다. 보고서는 별도의 안내에 동의한 뒤 연결하며 기존 신청서 동의만으로 보고서 조회를 시작하지 않습니다.

조회 연결 중 사용자가 누른 조회 버튼과 해당 요청 URL·본문·응답을 확인합니다. 요청 추적은 연결 준비 및 조회 클릭 직후의 제한된 시간에만 수행하며, 허용된 일반 헤더만 임시 처리합니다. Authorization 등 인증 헤더 값은 별도로 보관하거나 전달하지 않습니다. 전체 방문 기록이나 키 입력을 수집하지 않습니다.

이 확장 프로그램의 사용자 데이터 이용은 제한적 사용 요건을 포함한 Chrome 웹 스토어 사용자 데이터 정책을 준수합니다. 데이터는 신청서·보고서 확인, 알림과 자동 연결 기능에만 사용하며 광고, 판매, 신용 평가 목적으로 이용하거나 개발자 서버에 전송하지 않습니다.

보관과 삭제

설정과 자동 연결 정보, 알림 이력은 이 크롬 프로필에 보관합니다. ‘알림 기록 초기화’는 신청서와 보고서의 최근 알림·발송 이력을 삭제하며 두 자동 연결 정보는 유지합니다. 설정을 저장하면 두 자동 연결 정보가 삭제되어 새 연결이 필요합니다. ‘감시 중지’는 신청서, ‘보고서 감시 중지’는 보고서의 자동 확인을 각각 멈추되 저장 정보는 유지합니다. 확장 프로그램을 제거하면 동의 기록을 포함한 해당 확장 프로그램의 브라우저 저장 정보가 삭제됩니다.
